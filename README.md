# Курсовая работа по компьютерным языкам разметки

Курсовой проект по разработке сайта игровой платформы: цифровой дистрибутор видеоигр, издательский портал и информационный ресурс об игровой индустрии (по типу Steam / Lesta Games).

Макет сайта разработан в Figma на летней практике, по нему создаётся сайт и пояснительная записка.

| `Раздел 1. Аналитический обзор.docx` | Готовый первый раздел пояснительной записки, оформленный по СТП БГТУ 002-2007 |

## Оформление

Раздел 1 оформлен в соответствии с требованиями СТП БГТУ 002-2007:

- формат А4, поля: верхнее 20 мм, правое 10 мм, левое 23 мм, нижнее 15 мм;
- Times New Roman, 14 пт, чёрный цвет, одинарный интервал;
- абзацный отступ 1,25 см, выравнивание по ширине;
- заголовки полужирные, с абзацного отступа, без точки в конце;
- нумерация страниц в правом верхнем углу;
- таблицы с подписями вида «Таблица 1.1 – Название» и ссылками в тексте.
